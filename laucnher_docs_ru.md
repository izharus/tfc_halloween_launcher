## Работа с настройками игры пользователя 'options.txt'
- Каждый модпак хранит свой файл 'options.txt' в своей root_dir.
- Изначально файл настроек может быть скачен из папки mutable_data из object_storage,  
если такой файл заранее подготовят для данного модпака. Файлы mutable_data, соответственно,  
качаются на момент установки модпака/проверки файлов.
- Если во время запуска игры обнаруживается, что файла 'options.txt' не существует - тогда  
лаунчер попытается создать его самостоятельно:
    - Лаунчер спарсит настройки из последнего запущенного модпака, если раньше таковой  
    запускался с помощью лаунчера.
    - Если лаунчер ранее не запускал ни одного модпака - лаунчер попытается спарсить  
    настройки из стандартной директории с игрой пользователя (например .minecraft  
    на OS Windows.)
    - Если даже в там нету настроек - тогда лаунчер создаст свои настройки с единственным
    параметром - русским языком игры.
