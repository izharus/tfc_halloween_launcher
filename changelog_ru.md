## Версия 1.0.0 (10.11.2023)

### Новые возможности
- Добавлена поддержка нескольких серверов с разными модпаками (нам потребовался второй сервер только для тестов). В будущем мы можем запустить третий сервер, например, для версии 1.7.10.
- Реализовано автоматическое скачивание всех файлов лаунчера для нескольких модпаков. Файлы модов проверяются с использованием хэш-значений, и любые неизвестные моды удаляются.
- Улучшена информативность всех сообщений об ошибках установки.
- Добавлена возможность пропустить установку, если Minecraft для текущей активной конфигурации уже установлен.
- Обновлен дизайн элемента для установки шейдеров. Шейдеры будут автоматически устанавливаться/удаляться в зависимости от статуса флажка (выбран/снят).
- Улучшена информативность сообщений журнала.
- Обновлен URL установки Java.
- Другие небольшие улучшения интерфейса.

### Исправления ошибок
- Исправлены критические ошибки, приводившие к неожиданной остановке программы, если Java не была установлена в системе, или если она не была добавлена в переменную среды PATH, или при любых других ошибках во время установки.
- Исправлены критические ошибки, приводившие к неожиданной остановке программы, если возникала ошибка во время установки Minecraft.
- Убрано автоматическое перенаправление в браузер пользователя, если Java не найдена в системе пользователя. Ссылка на установку Java теперь вставляется в окно сообщения об ошибке.
- Упрощено указание наличия Java, теперь нет необходимости устанавливать именно Java 17.

### Примечание: Поддержка Windows 7
- Обратите внимание, что лаунчер не поддерживает Windows 7. Windows 7 - устаревшая операционная система, и создание совместимости может потребовать значительного времени и ресурсов. Даже крупные платформы, такие как Steam, прекратят поддержку Windows 7 в январе 2024 года. Рекомендуется обновиться до более поздней версии Windows.

## Версия 3.0.0 (01.11.2024)

### Новые возможности
- Скорость установки игры увеличилась в 7 раз (требуется хорошее интернет соединение).
- Оптимизирован способ хранения файлов игры. Ранее 10 разных версий игры  
занимали около 10гб. Сейчас - до 1,5 гб.
- Добавлена функция сброса пароля.
- Полностью обновлен дизайн, а следовательно, и внутрення архитектура.
- В лаунчер встроена возможность автоматических обновлений.
- Добавлена возможность выделение памяти для лаунчера.
- Добавлена поддержка более старых систем: Windows 7, 8, 8.1  
и 32 битных систем. Имейте ввиду, что 32битный лаунчер не сможет  
выделить более 1.5 гб памяти на игру.
- Добавлена возможность проводить проверку файлов по запросу пользователя.
- Добавлен парсинг настроек игры. Больше не придется менять язык и управление  
при первом запуске
- Полностью переработана логика загрузки серверов,  
теперь лаунчер может полноценно получать обновления для серверов.
- Добавлена графа "описание сервера"
- Добавлена возможность открытия папки любого установленного сервера.  
Ранее можно было открыть только папку лаунчера.

### Исправления ошибок
- Во время установки больше не должны появляться консольные окна.
- Больше не должны в редких случаях пропадать введенные данны пользователем.  
Логика хранения данных полностью переработана.
